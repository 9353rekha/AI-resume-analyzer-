
# 🚀 AI Resume Analyzer

A Python-based web application that analyzes resumes and compares their skills with job descriptions.

## 📌 Project Overview

The AI Resume Analyzer helps job seekers identify matching and missing skills based on job requirements.

It uses keyword-based matching to calculate a skill match percentage and provides suggestions for improving resumes.

## 🛠️ Technologies Used

- Python
- Streamlit
- PyMuPDF
- Plotly
- Regular Expressions (Regex)
- HTML and CSS

## ✨ Features

- Upload PDF resumes
- Extract resume text
- Compare resumes with job descriptions
- Calculate skill match percentage
- Display interactive doughnut charts
- Identify matching and missing skills
- Provide resume improvement suggestions
- Download analysis reports as TXT files
- Professional dashboard interface

## ▶️ How to Run

1. Install the required libraries:

   pip install -r requirements.txt

2. Start the application:

   streamlit run app.py

3. Open the local URL shown in your terminal.

## 📊 How It Works

1. User uploads a PDF resume.
2. User enters a job description.
3. The application extracts text from the resume.
4. It identifies recognized skills in both texts.
5. It calculates a keyword-based match percentage.
6. It displays results, charts, and recommendations.

## ⚠️ Disclaimer

This application uses keyword-based skill matching, not a trained AI model or an official Applicant Tracking System (ATS) score.
